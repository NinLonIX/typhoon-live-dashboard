# 沿海台风实况预警台

面向沿海居民的台风实况信息网站项目仓库。

## 当前内容

- [项目计划书](docs/PROJECT_PLAN.md)：产品目标、功能范围、预警分级、数据方案、技术路线、里程碑和验收标准。

## 计划中的核心信息

- 台风名称与编号
- 当前中心位置
- 移动方向与速度
- 最大风力、中心气压和影响范围
- 分级预警、发布时间、有效期和行动建议

## 本地开发约定

本仓库当前处于规划阶段。实现阶段建议使用 TypeScript，前端采用 React + Vite，地图采用 Leaflet，实时数据通过后端代理或 Serverless API 接入，并保留数据源、发布时间和更新时间。

## 安全提示

这是面向公众的风险提示工具，不能替代当地政府、气象部门和应急管理部门发布的正式指令。正式上线前必须完成数据源授权、异常数据处理和移动端可读性测试。
