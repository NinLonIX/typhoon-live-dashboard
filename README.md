# 沿海台风实况预警台

面向沿海居民的台风实况信息与分级预警网站演示仓库。

## 在线仓库

- GitHub：https://github.com/NinLonIX/typhoon-live-dashboard

## 当前内容

- [演示网页](index.html)：台风实况面板、路径示意图、四级预警和沿海城市影响列表。
- [项目计划书](docs/PROJECT_PLAN.md)：产品目标、功能范围、预警分级、数据方案、技术路线、里程碑和验收标准。

## 本地预览

这是无构建依赖的静态 HTML 页面，可直接双击 `index.html` 打开；也可以在仓库目录运行：

```powershell
npx serve .
```

页面当前使用虚构演示数据，首屏和数据说明区域均已标注“仅为演示使用”。正式接入前，需要完成权威数据源授权、字段校验、延迟监测、异常降级和人工复核。

## 计划中的核心信息

- 台风名称与编号
- 当前中心位置
- 移动方向与速度
- 最大风力、中心气压和影响范围
- 分级预警、发布时间、有效期和行动建议

## 技术约定

当前演示页使用原生 HTML、CSS 和 JavaScript，地图使用内嵌 SVG 路径示意，避免外部依赖。实现实时版本时，建议迁移到 TypeScript + React + Vite，地图采用 Leaflet，实时数据通过后端代理或 Serverless API 接入，并保留数据源、发布时间和更新时间。

## 安全提示

这是面向公众的风险提示工具，不能替代当地政府、气象部门和应急管理部门发布的正式指令。正式上线前必须完成数据源授权、异常数据处理和移动端可读性测试。
